## Project Overview

This is a documentation/study repository about the **Model Context Protocol (MCP)** — the open standard created by Anthropic for connecting AI models to external tools and data sources.

The repository currently contains reference documentation only (no source code, build system, or tests).

## Structure

- `doc/mcp_documento_completo.md` — Complete overview document covering MCP architecture (Host, Client, Server), communication transports (STDIO, HTTP, SSE), resource types (Tools, Resources, Prompts), use cases, and security considerations. Written in Portuguese.
