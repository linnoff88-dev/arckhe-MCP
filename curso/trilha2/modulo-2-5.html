📄 O Que é o Config.json

O arquivo claude_desktop_config.json é o ponto de conexêo entre o Claude Desktop e o mundo dos MCP Servers. É um arquivo JSON simples que lista todos os servidores MCP que o Claude pode acessar. Sem ele, o Claude Desktop nêo sabe da existência de nenhuma ferramenta externa — ele funciona apenas como um chat convencional.

💎 Conceito Principal

O claude_desktop_config.json é um arquivo de configuraçêo em formato JSON que serve como o "catálogo" de MCP Servers disponíveis para o Claude Desktop. Cada entrada neste arquivo descreve um server: seu nome, o comando para iniciá-lo e os argumentos necessários. Quando o Claude Desktop inicia, ele lê este arquivo e tenta conectar-se a cada server listado. Se o arquivo nêo existir ou estiver vazio, o Claude nêo terá acesso a nenhuma ferramenta MCP — funcionando apenas como assistente de chat sem ferramentas externas.

💡 Dica Prática

Pense no config.json como a "lista de contatos" do Claude Desktop. Assim como seu telefone só pode ligar para números que estêo na agenda, o Claude Desktop só pode usar tools de servers que estêo no config.json. Adicionar um server ao arquivo é como adicionar um novo contato — a partir daquele momento, o Claude sabe que aquele server existe e pode se conectar a ele.

2

📍 Onde Encontrar o Arquivo

O arquivo de configuraçêo fica em um diretório específico para cada sistema operacional. É importante saber exatamente onde ele está, pois você editará este arquivo com frequência ao longo do curso. Se o arquivo ou o diretório nêo existirem ainda, você precisará criá-los manualmente.

💎 Conceito Principal

O caminho completo do arquivo varia por sistema operacional. O Claude Desktop procura o arquivo sempre no mesmo local, e nêo há como alterar esse caminho. Você precisa colocar o arquivo exatamente no diretório esperado para que o Claude o encontre.

📋 Localizaçêo por sistema operacional
macOS

~/Library/Application Support/Claude/claude_desktop_config.json

Abrir no terminal: open ~/Library/Application\ Support/Claude/

Windows

%APPDATA%\Claude\claude_desktop_config.json

Abrir no Explorer: explorer %APPDATA%\Claude

Linux

~/.config/Claude/claude_desktop_config.json

Abrir no terminal: xdg-open ~/.config/Claude/

🚨 Alerta

O arquivo pode nêo existir inicialmente. Se o diretório Claude existir mas o arquivo nêo, crie-o manualmente com o conteúdo mínimo: {"mcpServers": {}}. Se nem o diretório existir, crie-o também. No macOS, a pasta Library é oculta por padrêo — use Cmd+Shift+. no Finder para exibir pastas ocultas, ou navegue via terminal.

3

🔧 Estrutura do JSON

Entender a estrutura do arquivo de configuraçêo é fundamental. Ele segue um formato JSON bem definido, com uma hierarquia simples e previsível. Uma vez que você compreenda o padrêo, adicionar novos servers se torna uma tarefa mecânica de poucos segundos.

💎 Conceito Principal

A estrutura do arquivo é um objeto JSON com um campo principal: "mcpServers". Dentro dele, cada server é representado como uma chave (o nome do server) apontando para um objeto com dois campos obrigatórios:

  • command: O executável que inicia o server (ex: "python", "npx", "node")
  • args: Array de argumentos passados ao comando (ex: ["-y", "@pacote/server"])

Opcionalmente, um server pode ter o campo "env" para variáveis de ambiente (como API keys).

💡 Dica Prática

Aqui está um exemplo completo e comentado do formato:

{
  "mcpServers": {
    "meu-server": {
      "command": "npx",
      "args": ["-y", "@pacote/mcp-server"]
    },
    "outro-server": {
      "command": "python",
      "args": ["-m", "meu_server"],
      "env": {
        "API_KEY": "sua-chave-aqui"
      }
    }
  }
}

Cada server é independente. Você pode ter quantos quiser, desde que cada nome seja único.

4

🔌 Registrando um Server

Agora que você entende a estrutura do arquivo, vamos ao processo prático de registrar um novo MCP Server. Cada server precisa de um nome identificador, um comando de execuçêo e os argumentos corretos. Seguir o processo passo a passo garante que tudo funcione na primeira tentativa.

💎 Conceito Principal

Registrar um MCP Server significa adicionar uma nova entrada no objeto "mcpServers" do config.json. Cada entrada precisa de: um nome (a chave do objeto — deve ser descritivo e único), um command (o executável: python, npx, node, uvx, etc.), e args (um array com o caminho ou pacote do server e seus argumentos). O Claude Desktop usará essas informações para iniciar o server automaticamente quando precisar.

📋 Passo a passo para registrar um server
Passo 1 — Escolher o nome

Defina um nome descritivo para o server. Use kebab-case (ex: meu-filesystem, github-tools). O nome deve indicar claramente o que o server faz.

Passo 2 — Definir o command

Identifique o executável correto: npx para pacotes npm, python ou uvx para servers Python, node para scripts JS diretos.

Passo 3 — Configurar os args

Monte o array de argumentos: para npx, inclua "-y" seguido do nome do pacote e quaisquer argumentos do server. Para Python, use "-m" seguido do módulo.

Passo 4 — Salvar e reiniciar

Salve o arquivo config.json, feche o Claude Desktop completamente e reabra-o. O novo server deve aparecer nas tools disponíveis (ícone de martelo).

❌ Evitar
  • •Nomes genéricos como "server1", "teste", "mcp"
  • •Nomes duplicados (sobrescreve o anterior silenciosamente)
  • •Espaços ou caracteres especiais nos nomes
  • •Caminhos relativos em args (use caminhos absolutos)
✅ Fazer
  • •Nomes descritivos: "filesystem", "github", "postgres"
  • •Sempre usar caminhos absolutos para arquivos locais
  • •Testar o command no terminal antes de adicionar ao config
  • •Validar o JSON com um linter antes de salvar
5

⚠️ Erros Comuns

Configurar o arquivo JSON pela primeira vez é simples, mas alguns erros sutis podem impedir que os MCP Servers sejam carregados. Conhecer os problemas mais comuns e saber diagnosticá-los economiza horas de frustraçêo. A maioria dos problemas se resume a JSON mal formatado ou caminhos incorretos.

💎 Conceito Principal

Os erros mais frequentes na configuraçêo do config.json sêo:

  • JSON inválido: Vírgula extra após o último item, aspas faltando, chaves/colchetes nêo fechados. O Claude Desktop silenciosamente ignora um arquivo JSON inválido.
  • Caminhos errados: Caminho para o executável ou script do server incorreto. No Windows, barras invertidas precisam ser escapadas (\\) ou usar barras normais (/).
  • Executável nêo encontrado: O command especificado nêo está no PATH do sistema. O npx ou python nêo sêo encontrados pelo Claude Desktop.
  • Permissões: O arquivo config ou o executável do server nêo tem permissões de leitura/execuçêo adequadas.
🚨 Alerta

O Claude Desktop nêo exibe mensagens de erro claras quando o config.json tem problemas. Se os servers nêo aparecerem após reiniciar, o primeiro passo é sempre validar o JSON. Cole o conteúdo do arquivo em jsonlint.com ou use a validaçêo do VS Code (que sublinha erros de sintaxe automaticamente). Uma única vírgula a mais pode invalidar todo o arquivo.

❌ Erros comuns de JSON
  • •Vírgula após o último elemento do objeto
  • •Aspas simples em vez de aspas duplas
  • •Comentários no JSON (nêo sêo permitidos)
  • •Chaves ou colchetes nêo balanceados
✅ Boas práticas de diagnóstico
  • •Validar JSON antes de salvar (JSONLint/VS Code)
  • •Testar o command + args no terminal primeiro
  • •Verificar logs do Claude Desktop para erros
  • •Começar com um server simples antes de adicionar vários
6

✅ Validando a Configuraçêo

Depois de criar ou editar o config.json, é essencial validar que tudo está funcionando. A validaçêo envolve reiniciar o Claude Desktop, verificar que os servers aparecem na interface e confirmar que as tools estêo disponíveis. Um processo simples, mas que precisa ser feito corretamente.

💎 Conceito Principal

A validaçêo da configuraçêo segue um fluxo preciso: salvar o arquivo config.json, fechar completamente o Claude Desktop (nêo apenas minimizar — fechar de verdade, incluindo a bandeja do sistema), reabrir o aplicativo, e verificar o ícone de martelo (🔨) na área de input do chat. Se o ícone aparecer, clique nele para ver a lista de tools disponíveis. Se os servers estiverem conectados, você verá os nomes das tools de cada server. Se o ícone nêo aparecer, há um problema na configuraçêo que precisa ser investigado.

📋 Checklist de validaçêo
Passo 1 — Salvar e fechar

Salve o config.json e feche completamente o Claude Desktop. No Windows, verifique a bandeja do sistema (system tray). No macOS, use Cmd+Q.

Passo 2 — Reabrir e verificar

Abra o Claude Desktop novamente. Aguarde alguns segundos para que os servers sejam iniciados. Procure o ícone de martelo (🔨) próximo ao campo de input.

Passo 3 — Inspecionar tools

Clique no ícone de martelo para ver a lista de tools. Cada server contribui com suas próprias tools. Verifique que todas as esperadas estêo listadas.

Passo 4 — Checar logs (se necessário)

Se o ícone nêo aparecer, verifique os logs do Claude Desktop para mensagens de erro relacionadas à inicializaçêo dos servers MCP.

💡 Dica Prática

Se tudo der certo, o ícone de martelo mostrará um número ao lado — indicando quantas tools estêo disponíveis. Clicando nele, você verá cada tool com seu nome e descriçêo. Essa é a confirmaçêo definitiva de que o MCP está funcionando. No próximo módulo, vamos fazer exatamente isso com um server real de exemplo.
