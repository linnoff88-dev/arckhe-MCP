🐍 Qué es Python y por qué usarlo

Python es el lenguaje de programación más popular del mundo para el desarrollo de IA, la automatización y el scripting. Su sintaxis clara y legible lo hace ideal tanto para principiantes como para profesionales experimentados. En el contexto de MCP, Python es la opción número uno gracias al SDK oficial FastMCP, que simplifica enormemente la creación de servidores MCP.

💎 Concepto principal

Python es un lenguaje de programación de alto nivel, interpretado y de tipado dinámico. En el ecosistema MCP, Python destaca por ofrecer el SDK FastMCP — una biblioteca que permite crear servidores MCP completos con pocas líneas de código. La combinación de la simplicidad de Python y la practicidad de FastMCP permite crear un MCP Server funcional en menos de 10 minutos, incluso si nunca has programado.

📊 Datos e investigación

Python se usa en 60%+ de los MCP Servers publicados por la comunidad. El lenguaje lidera el índice TIOBE de popularidad desde hace años consecutivos y cuenta con el mayor ecosistema de bibliotecas de IA del mundo, incluidas TensorFlow, PyTorch, LangChain y, por supuesto, el FastMCP. La comunidad de Python aporta más de 500.000 paquetes a PyPI, lo que garantiza que siempre encontrarás una biblioteca para cualquier necesidad de integración.

📦 Instalando Python 3.11+

El primer paso para crear MCP Servers en Python es instalar la versión correcta del lenguaje. FastMCP requiere Python 3.11 o superior, ya que utiliza recursos modernos del lenguaje, como tipado avanzado y asyncio mejorado. El proceso de instalación varía según el sistema operativo, pero es sencillo en todos ellos.

💎 Concepto principal

O Python 3.11+ es necesario porque FastMCP y el SDK oficial de MCP utilizan funciones introducidas en esa versión, como Exception Groups, mejoras significativas de rendimiento (hasta 25% más rápido que 3.10) y tipado avanzado con soporte nativo para tipos genéricos. Instalar una versión anterior puede causar errores de importación e incompatibilidades difíciles de diagnosticar.

📋 Instalación por sistema operativo
Windows

Accede python.org/downloads, descarga el instalador y ejecútalo. Marca obligatoriamente la opción "Add Python to PATH" antes de hacer clic en Install. Después de la instalación, abre PowerShell y prueba con python --version.

macOS

Instala mediante Homebrew: brew install python. Homebrew ya configura el PATH automáticamente. Si no tienes Homebrew, instálalo primero en brew.sh.

Linux

Ubuntu/Debian: sudo apt update && sudo apt install python3.11. Fedora/RHEL: sudo dnf install python3.11. La mayoría de las distribuciones ya vienen con Python, pero puede ser una versión anterior.

🚨 Alerta

¡Comprueba la versión mínima! Ejecuta python --version o python3 --version y confirma que es 3.11 o superior. Versiones como 3.9 o 3.10 pueden parecer funcionar al principio, pero causarán errores cuando intentes usar FastMCP. En Linux, el comando puede ser python3 en lugar de python.

⚡ Qué es uv

O uv es un gestor de paquetes y entornos de Python de nueva generación, escrito en Rust por la empresa Astral. Reemplaza simultáneamente a pip, venv y pip-tools, y ofrece una experiencia unificada y mucho más rápida. Si Python es el motor de tus MCP Servers, uv es el combustible de alto rendimiento que hace que todo funcione sin fricciones.

💎 Concepto principal

O uv es un gestor de paquetes de Python ultrarrápido, escrito en Rust, que unifica las funcionalidades de pip (instalación de paquetes), venv (entornos virtuales) y pip-tools (resolución de dependencias) en una sola herramienta. Resuelve e instala dependencias de 10 a 100 veces más rápido que el pip tradicional, cuenta con lockfiles nativos para builds reproducibles y crea entornos virtuales automáticamente cuando es necesario.

💡 Consejo práctico

Piensa en uv como el "npm de Python" — una herramienta moderna que lo gestiona todo: creación de proyectos, instalación de paquetes, entornos aislados y lockfiles. Mientras que pip te exige crear un venv manualmente, instalar paquetes por separado y gestionar requirements.txt a mano, uv hace todo esto con comandos simples como uv init e uv add.

📊 Datos e investigación

En benchmarks reales, uv instala dependencias 10-100x más rápido que el pip. Un proyecto con 50 dependencias que tarda 45 segundos en el pip se resuelve en menos de 1 segundo con uv. El proyecto superó 30.000 estrellas en GitHub en menos de un año desde su lanzamiento, y fue adoptado por empresas como Pydantic y FastAPI, así como por el SDK oficial de MCP. Astral, la empresa creadora de uv, recibió más de US$ 30 millones en inversiones para desarrollar herramientas de Python de nueva generación.

🔧 Instalación de uv

La instalación de uv es rápida y sencilla: basta con un solo comando en la terminal. uv se instala como un binario independiente, sin depender de pip ni de ninguna otra herramienta de Python instalada previamente. Esto significa que funciona de inmediato, sin complicaciones de dependencias circulares.

💎 Concepto principal

uv se distribuye como un binario independiente compilado en Rust; no es un paquete de Python instalado mediante pip. Esto elimina el clásico problema del "huevo y la gallina": no necesitas tener pip para instalar el gestor de paquetes. El script de instalación oficial detecta automáticamente tu sistema operativo y arquitectura, descarga el binario correcto y configura el PATH.

💡 Consejo práctico

Comandos de instalación por sistema operativo:

macOS / Linux curl -LsSf https://astral.sh/uv/install.sh | sh
Windows (PowerShell) powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
❌ Evitar
  • •Instalar uv mediante pip (pip install uv)
  • •Usar versiones desactualizadas de uv
  • •Ignorar la configuración del PATH después de la instalación
  • •Mezclar pip y uv en el mismo proyecto
✅ Hacer
  • •Usar el script oficial de instalación
  • •Reiniciar el terminal después de instalar
  • •Comprobar con uv --version
  • •Actualizar regularmente con uv self update

✅ Verificando la instalación

Después de instalar Python y uv, es fundamental verificar que ambas herramientas funcionen correctamente y estén accesibles desde la terminal. Los problemas de PATH son la causa más común de frustración para quienes empiezan: asegurémonos de que todo esté configurado antes de continuar.

💎 Concepto principal

A verificación de la instalación consiste en confirmar que los comandos python e uv el terminal los reconoce y ejecuta las versiones correctas. Si un comando devuelve «no reconocido» o «command not found», significa que el ejecutable no está en el PATH del sistema: la lista de directorios donde el terminal busca programas.

📋 Lista de verificación
Paso 1 — Verificar Python

Ejecuta python --version (o python3 --version en Linux/Mac). Debe mostrar Python 3.11.x o superior.

Paso 2 — Verificar uv

Ejecuta uv --version. Debe mostrar la versión instalada (ej.: uv 0.5.x o superior).

Paso 3 — Probar uv con Python

Ejecuta uv python list para verificar que uv detecta las instalaciones de Python en tu sistema.

🚨 Alerta — Problemas comunes
  • •"command not found" — PATH no está configurado. En Windows, reinstala Python y marca "Add to PATH". En Mac/Linux, agrega el directorio a tu ~/.bashrc o ~/.zshrc.
  • •Versión incorrecta — Si aparece Python 3.9 o 3.10, tienes instalada una versión antigua. En Linux, usa python3.11 explícitamente o actualiza.
  • •Terminal antiguo — Cierra y vuelve a abrir la terminal después de la instalación para que los cambios en PATH surtan efecto.
6

🧪 Primera prueba

Ahora que Python y uv están instalados y verificados, hagamos una prueba práctica: crear un proyecto Python con uv e instalar FastMCP. Esta prueba confirma que todo el entorno está configurado correctamente y listo para crear MCP Servers.

💎 Concepto principal

El comando uv init crea un proyecto Python nuevo con la estructura estándar, incluida pyproject.toml (configuración del proyecto), un directorio para el código fuente y un archivo .python-version. El comando uv add instala paquetes y los registra automáticamente como dependencias, creando un entorno virtual aislado si es necesario. Juntos, estos dos comandos sustituyen todo el ritual de python -m venv + pip install + edición manual del requirements.txt.

💡 Consejo práctico

Ejecuta los siguientes comandos paso a paso en el terminal:

1. Crear el proyecto uv init meu-projeto
2. Entrar en la carpeta cd meu-projeto
3. Instalar FastMCP uv add fastmcp

Si FastMCP se instala sin errores, tu entorno está 100% listo ¡para crear MCP Servers!

❌ Evitar
  • •Instalar paquetes globalmente con pip
  • •Omitir la verificación de FastMCP
  • •Crear proyectos sin uv init
  • •Ignorar errores de instalación
✅ Hacer
  • •Siempre usa uv init para proyectos nuevos
  • •Usar uv add en lugar de pip install
  • •Comprobar que fastmcp aparezca en pyproject.toml
  • •Hacer commit del uv.lock en Git
