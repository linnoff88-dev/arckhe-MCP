💻 Qué es la terminal

La terminal es una interfaz de texto que permite controlar tu computadora escribiendo comandos en lugar de hacer clic en íconos. Aunque al principio parezca intimidante, la terminal es la herramienta más poderosa que un desarrollador tiene a su disposición. Todos los MCP Servers se inician, prueban y depuran desde la terminal; dominarla es esencial para este curso.

💎 Concepto principal

O terminal (también llamado consola, shell o línea de comandos) es una interfaz basada en texto para interactuar con el sistema operativo. Mientras que la interfaz gráfica te limita a las opciones visibles en la pantalla, la terminal te da acceso directo a todo que puede hacer el sistema. En el macOS, usa Terminal o iTerm2. En Windows, usa PowerShell o WSL (Windows Subsystem for Linux). En Linux, cualquier emulador de terminal funciona (GNOME Terminal, Konsole, Alacritty, etc.).

💡 Consejo práctico

Piensa en la terminal como el control remoto más potente de tu computadora. La interfaz gráfica es como los botones del control remoto del televisor: te limita a algunas funciones predefinidas. El terminal es como tener acceso al menú de ingeniería del televisor: puedes hacer absolutamente cualquier cosa, siempre que sepas el comando correcto. Y en el mundo de MCP, todo ocurre en el terminal.

📂 Navegando entre carpetas

La navegación por el sistema de archivos es la habilidad más fundamental de la terminal. Así como haces clic en carpetas en el explorador de archivos, en la terminal usas comandos para entrar en directorios, listar su contenido y descubrir dónde estás. Estos comandos se usarán constantemente al trabajar con MCP Servers.

💎 Concepto principal

Los comandos esenciales de navegación son:

  • cd pasta — Entra en un directorio (Change Directory)
  • ls — Muestra archivos y carpetas (Mac/Linux). En Windows: dir
  • pwd — Muestra el directorio actual (Print Working Directory)
  • cd ~ — Va a la carpeta home del usuario
  • cd .. — Vuelve un nivel (directorio principal)
📋 Navegación paso a paso
Paso 1 — Descubre dónde estás

Ejecuta pwd para ver tu directorio actual. Por lo general, empiezas en la carpeta home: /home/seuusuario (Linux) o /Users/seuusuario (Mac).

Paso 2 — Mira qué hay aquí

Ejecuta ls para listar los archivos y carpetas. Usa ls -la para ver archivos ocultos y detalles como el tamaño y la fecha de modificación.

Paso 3 — Navega y explora

Usa cd Documents para entrar en la carpeta Documents. Usa cd .. para volver. Combina: cd ../outra-pasta vuelve y entra en otra carpeta de una sola vez.

❌ Evitar
  • •Escribir rutas largas manualmente
  • •Usar espacios en los nombres de carpetas sin comillas
  • •Ejecutar comandos sin saber dónde estás
  • •Ignorar mensajes de error
✅ Hacer
  • •Usar Tab para autocompletar rutas
  • •Siempre verifica con pwd antes de actuar
  • •Usar cd ~ para volver rápidamente a home
  • •Practicar la navegación a diario

📄 Manipulando archivos

Además de navegar, necesitas saber crear, copiar, mover y eliminar archivos y carpetas desde la terminal. Estas operaciones son esenciales para organizar tus proyectos MCP, crear archivos de configuración y administrar el código fuente de tus servidores.

💎 Concepto principal

Los comandos esenciales para manipular archivos son:

  • mkdir pasta — Crea una carpeta nueva (Make Directory)
  • touch arquivo — Crea un archivo vacío (Mac/Linux). Windows: echo. > arquivo
  • cp origem destino — Copia un archivo
  • mv origem destino — Mueve o cambia el nombre de un archivo
  • rm arquivo — Elimina un archivo (¡permanentemente!)
💡 Consejo práctico

Practica creando la estructura de un proyecto MCP:

mkdir meu-mcp-server
cd meu-mcp-server
touch server.py README.md
mkdir src tests
🚨 Alerta

Mucho cuidado con rm -rf! Este comando elimina carpetas y todo su contenido permanentemente, sin papelera, sin confirmación y sin posibilidad de recuperación. Nunca lo ejecutes rm -rf / o rm -rf ~ — esto puede destruir todo tu sistema. Comprueba siempre la ruta con pwd e ls antes de borrar cualquier cosa.

📝 Cómo editar archivos

Para crear y modificar MCP Servers, necesitas editar archivos de código. Hay editores de texto en la terminal (como nano y vim) y editores gráficos con integración con la terminal (como VS Code). Para este curso, recomendamos VS Code como editor principal y el nano como alternativa rápida en la terminal.

💎 Concepto principal

Las tres herramientas de edición más útiles para el curso:

  • nano arquivo — Editor sencillo en la terminal. Ctrl+O para guardar, Ctrl+X para salir. Ideal para ediciones rápidas.
  • code arquivo — Se abre en VS Code. Requiere que VS Code esté instalado y que el comando code configurado en el PATH.
  • cat arquivo — Muestra el contenido de un archivo en la terminal sin editarlo. Es útil para revisar configuraciones rápidamente.
❌ Evitar
  • •Usar vim sin saber cómo salir (escribe :q!)
  • •Editar archivos del sistema sin sudo
  • •Usar el Bloc de notas para el código (Windows)
  • •Guardar archivos con la extensión incorrecta
✅ Hacer
  • •Usar VS Code con la extensión de Python/TS
  • •Usar nano para ediciones rápidas en el terminal
  • •Usar cat para verificar contenidos
  • •Instalar extensiones de resaltado de sintaxis

🔍 Buscando y filtrando

A medida que tus proyectos crecen, encontrar archivos y buscar texto específico dentro del código se vuelve esencial. El terminal ofrece potentes herramientas de búsqueda que son mucho más rápidas que cualquier interfaz gráfica, especialmente útiles para depurar MCP Servers y encontrar configuraciones.

💎 Concepto principal

Las tres herramientas de búsqueda esenciales:

  • find . -name "*.py" — Busca archivos por nombre. El punto (.) significa «a partir del directorio actual».
  • grep "texto" arquivo — Busca texto dentro de archivos. Usa -r para buscar recursivamente en carpetas.
  • | — El pipe encadena comandos: la salida de uno se convierte en la entrada del siguiente. Ej: ls | grep "server".
💡 Consejo práctico

Ejemplos prácticos para proyectos MCP:

grep -r "fastmcp" . — Encuentra todas las referencias a FastMCP en el proyecto
find . -name "*.json" — Muestra todos los archivos JSON (configuración de MCP)
cat config.json | grep "server" — Muestra las líneas con «server» en la configuración
📊 Datos e investigación

Los desarrolladores que dominan la terminal son, en promedio 30% más productivos que aquellos que dependen exclusivamente de interfaces gráficas, según investigaciones de Stack Overflow. El comando grep se usa solo miles de millones de veces al día en todo el mundo. Herramientas modernas como ripgrep (rg) son aún más rápidas — permiten buscar en proyectos con millones de líneas en milisegundos.

⚡ Atajos esenciales

Dominar los atajos de teclado en la terminal transforma tu velocidad de trabajo. En lugar de escribir cada carácter de una ruta larga, puedes autocompletar con Tab. En lugar de volver a escribir un comando, puedes recuperarlo del historial. Estos atajos parecen pequeños, pero ahorran horas a lo largo de un proyecto.

💎 Concepto principal

Los cuatro atajos que todo desarrollador de MCP necesita conocer:

Tab

Completa automáticamente nombres de archivos, carpetas y comandos. Presiona dos veces para ver todas las opciones.

↑ / ↓

Navega por el historial de comandos. Recupera cualquier comando anterior sin volver a escribirlo.

Ctrl + C

Cancela el comando actual. Esencial para detener MCP Servers en ejecución.

Ctrl + L

Limpia la pantalla del terminal. Equivale al comando clear.

💡 Consejo práctico

Atajos extra que aceleran aún más tu flujo:

  • •Ctrl + R — Busca en el historial de comandos. Escribe parte de un comando anterior y aparecerá automáticamente.
  • •Ctrl + A / Ctrl + E — Va al inicio/final de la línea. Útil para corregir comandos largos.
  • •Ctrl + W — Borra la palabra anterior. Es más rápido que mantener presionada la tecla Backspace.
  • •!! — Repite el último comando. sudo !! vuelve a ejecutar el último comando con sudo.
