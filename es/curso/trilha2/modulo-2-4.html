🖥️ Qué es Claude Desktop

Claude Desktop es la aplicación oficial de Anthropic que lleva el modelo Claude directamente a tu computadora. Más que un simple chat, funciona como un Host MCP completo, que incluye el modelo de lenguaje Claude y un cliente MCP integrado que permite la conexión con servidores externos. Esto lo convierte en la pieza central de nuestro entorno de desarrollo MCP.

💎 Concepto principal

O Claude Desktop es una aplicación de escritorio de Anthropic que funciona como Host MCP. En la arquitectura MCP, el Host es la aplicación que contiene el modelo de IA y el Client MCP integrado. Esto significa que, al instalar Claude Desktop, obtienes automáticamente: el modelo Claude para procesar lenguaje natural, un Client MCP capaz de conectarse a múltiples MCP Servers y una interfaz gráfica para interactuar con todo ello. Es gratis para uso básico y será la herramienta principal a lo largo de todo el curso.

📊 Datos e investigación

Claude Desktop fue uno de los primeros hosts MCP disponibles para el público; Anthropic lo lanzó junto con la especificación del protocolo. Es compatible con múltiples MCP Servers simultáneos, lo que permite que Claude acceda a decenas de herramientas al mismo tiempo. La aplicación está disponible para Windows, macOS y Linux, que cubre los tres principales sistemas operativos que usan los desarrolladores. Anthropic mantiene actualizaciones periódicas que amplían las capacidades MCP de la aplicación de escritorio.

📥 Descarga e instalación

El proceso de descarga e instalación de Claude Desktop es directo y sencillo. Anthropic ofrece instaladores nativos para cada sistema operativo, lo que garantiza una experiencia de instalación familiar y sin sorpresas. En pocos minutos, tendrás la aplicación lista para usar.

💎 Concepto principal

Claude Desktop está disponible para descargar en claude.ai/download. El sitio detecta automáticamente tu sistema operativo y ofrece el instalador correcto. Para Windows, recibes un archivo .exe que ejecuta el instalador estándar. Para macOS, un archivo .dmg que solo tienes que arrastrar a la carpeta Aplicaciones. Para Linux, hay paquetes .deb (Ubuntu/Debian) y .AppImage (universal) disponibles. En la mayoría de los casos, la instalación no requiere privilegios de administrador.

📋 Pasos para la instalación
Paso 1

Accede claude.ai/download en tu navegador. El sitio detectará automáticamente tu sistema operativo y mostrará el botón de descarga correcto.

Paso 2

Descarga el instalador y ejecútalo. Windows: haz doble clic en el .exe y sigue el asistente. Mac: abre el .dmg y arrastra el ícono a Aplicaciones. Linux: instala el .deb con sudo dpkg -i o ejecuta el .AppImage.

Paso 3

Abre Claude Desktop después de la instalación. En el primer inicio, se te dirigirá a la pantalla de inicio de sesión. La aplicación estará lista para configurarse.

🚨 Alerta

Claude Desktop requiere una cuenta de Anthropic para que funcione. Si aún no tienes una, créala gratis en claude.ai antes de continuar. El plan gratuito es suficiente para seguir todo el curso. Asegúrate también de que tu sistema cumpla los requisitos mínimos: Windows 10+, macOS 12+ o una distribución moderna de Linux compatible con .deb o AppImage.

3

🔑 Configuración inicial

Al abrir Claude Desktop por primera vez, pasarás por un proceso rápido de configuración inicial. Es sencillo e intuitivo: solo tienes que iniciar sesión con tu cuenta de Anthropic, aceptar los términos de uso y familiarizarte con la interfaz principal. En menos de dos minutos, estarás listo para usar Claude localmente.

💎 Concepto principal

La configuración inicial de Claude Desktop consta de tres pasos sencillos: iniciar sesión con tu cuenta de Anthropic (correo electrónico y contraseña o inicio de sesión social), aceptar los términos de uso y política de privacidad, y explorar la interfaz principal. La interfaz consta de un campo de chat central donde conversas con Claude, una barra lateral para administrar conversaciones y un menú de configuración donde más adelante veremos las opciones relacionadas con MCP. En este momento, Claude funciona como un asistente de chat estándar, todavía sin acceso a herramientas externas.

💡 Consejo práctico

Aprovecha este momento para explorar la interfaz sin prisa. Envía algunos mensajes de prueba, crea una conversación nueva y prueba el atajo de teclado para iniciar una conversación (generalmente Ctrl+N o Cmd+N). Familiarízate con la barra lateral y el botón de configuración. Cuanto más cómodo te sientas con la interfaz básica, más fácil será cuando empecemos a agregar MCP Servers y la interfaz incorpore nuevos elementos visuales.

4

🔌 Dónde se encuentran los MCP Servers

La configuración de los MCP Servers en Claude Desktop se hace mediante un archivo JSON específico. Este archivo es el núcleo de la integración MCP: ahí declaras a qué servers puede acceder Claude, cómo iniciarlos y qué argumentos pasarles. Saber dónde se encuentra en tu sistema operativo es esencial para los siguientes pasos.

💎 Concepto principal

El archivo de configuración de los MCP Servers se llama claude_desktop_config.json y se encuentra en distintas ubicaciones según el sistema operativo:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%/Claude/claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json

Claude Desktop lee este archivo al iniciarse. Cualquier cambio requiere que reinicies la aplicación para que se aplique.

💡 Consejo práctico

Para navegar hasta el archivo de configuración, usa la terminal. En macOS: open ~/Library/Application\ Support/Claude/. En el Windows: explorer %APPDATA%\Claude. En el Linux: xdg-open ~/.config/Claude/. Si la carpeta o el archivo aún no existen, no te preocupes: los crearemos en el próximo módulo. Muchas veces el archivo solo se crea después de la primera configuración manual.

❌ Evitar
  • •Editar el archivo con Claude Desktop abierto sin reiniciarlo después
  • •Poner el archivo en una ubicación distinta de la predeterminada del sistema operativo
  • •Usar editores que agregan BOM o formato invisible
  • •Intentar encontrar configuraciones de MCP en la interfaz gráfica
✅ Hacer
  • •Usar VS Code u otro editor con compatibilidad con JSON
  • •Siempre reinicia Claude Desktop después de editar el config
  • •Haz una copia de seguridad del archivo antes de hacer cambios importantes
  • •Validar el JSON antes de guardarlo (JSONLint o una extensión del editor)
5

✅ Verificando la instalación

Antes de continuar con los próximos módulos, es importante verificar que todo funcione correctamente. Una instalación exitosa de Claude Desktop es un requisito previo para todo lo demás del curso. Vamos a hacer una lista de verificación completa para asegurarnos de que no quede nada pendiente.

💎 Concepto principal

La verificación de la instalación abarca cuatro puntos esenciales: el se abre la aplicación sin errores ni crashes, el el inicio de sesión funciona y puedes acceder a tu cuenta, el el chat responde a los mensajes con normalidad (lo que indica la conexión con el modelo), y el existe el directorio de configuración en la ruta esperada para tu sistema operativo. Si estos cuatro puntos están bien, la instalación está completa y lista para recibir configuraciones MCP.

📋 Lista de verificación
Comprobación 1 — La aplicación se abre

Haz clic en el ícono de Claude Desktop. Debería abrirse sin mensajes de error, fallas ni bloqueos. La pantalla de chat debería aparecer con normalidad.

Comprobación 2 — El inicio de sesión funciona

Debes haber iniciado sesión con tu cuenta de Anthropic. Si te pidió iniciar sesión, ingresa tus credenciales y confirma que la autenticación se haya completado correctamente.

Comprobación 3 — El chat responde

Envía un mensaje simple como "¡Hola!" y verifica que Claude responda. Esto confirma que la conexión con el modelo funciona.

Comprobación 4 — El directorio config existe

Navega hasta el directorio de configuración de tu OS y confirma que existe. Si el archivo claude_desktop_config.json si aún no existe, no pasa nada: lo crearemos en el próximo módulo.

🚨 Alerta

Si Claude Desktop no se abre o muestra errores, intenta: reinstalar la aplicación, verificar si tu sistema operativo está actualizado, desactivar temporalmente el antivirus (algunos bloquean la primera ejecución) o revisar la página de estado de Anthropic por posibles interrupciones del servicio. Si el chat no responde, revisa tu conexión a Internet: Claude Desktop necesita acceso a la red para funcionar.

6

🧪 Primer uso

Con Claude Desktop instalado y en funcionamiento, vamos a hacer el primer uso intencional. El objetivo es verificar que la comunicación con el modelo funcione perfectamente y, al mismo tiempo, observar qué falta todavía: las herramientas MCP. Este contraste será fundamental para entender el valor que aportarán los MCP Servers en los próximos módulos.

💎 Concepto principal

Envía el siguiente mensaje a Claude: "Hola, ¿cómo puedes ayudarme?". Claude debería responder con normalidad, enumerando sus capacidades de lenguaje natural. Ahora observa la interfaz con atención: nota que no hay un ícono de martillo (🔨) en el área de entrada. Este ícono aparece cuando hay MCP Servers conectados y tools disponibles. Si no aparece, se confirma que, en este momento, Claude funciona solo como asistente de chat — sin acceso a herramientas externas. En los próximos módulos, al configurar MCP Servers, aparecerá este ícono y Claude tendrá superpoderes.

💡 Consejo práctico

Prueba pedirle a Claude algo que él no puede hacerlo sin herramientas: "Lee el archivo README.md de mi carpeta de proyectos" o "¿Cómo está el clima ahora en mi ciudad?". Te explicará que no tiene acceso a archivos ni a Internet. Guarda esta experiencia en la memoria: cuando configuremos los MCP Servers, pedirás exactamente lo mismo y Claude ejecutarlas de verdad. La diferencia será impresionante.
